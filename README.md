## 看懂配置表再下单：四个容易吃亏的地方

同样写着“2 核 2GB”，实际体验可能差出一倍，差别藏在参数细节里。

- **存储看类型**：NVMe SSD > 普通 SSD > 机械硬盘。表里 ByteVirt 的东京、新加坡档标注了 NVMe RAID1，HostDare 是 NVMe，没标注的按普通 SSD 理解。
- **CPU 看共享还是专属**：标注 Fair Share 或 shared 的是共享核，高负载时会被邻居拖慢；标注 dedicated 或给出具体型号（如 AMD EPYC）的更接近独占。
- **内存看专属还是共享**：Dedicated（专属）内存是实打实划给你的，共享内存在宿主机吃紧时会被压缩。

## 下单前后的避坑清单

容易吃亏的地方集中在两处：配置选择和安全设置。

买之前：

- 确认架构是 KVM。OpenVZ 架构的便宜货超售严重，标称的“专用”核实际和几百个邻居抢资源，RackNerd 主打的 KVM 机型可以避开这个坑。
- 数据中心离用户越近越好，经验法则是 1000 公里以内。给印度用户用美国机器，每个请求要多扛约 200ms 延迟，中国用户选美国机房同理。
- 内存宁可往上走一档：1GB 跑 WordPress 会 swap，2GB 跑轻站够用，电商站 4GB 起步。

开通之后：

- 别用 root 加密码登录。默认配置的 root 密码 SSH 在公网上几分钟内就会被爆破，先建非 root 用户、配好密钥登录，再关掉密码登录。
- ufw 加 fail2ban 是防火墙和防爆破的最低配组合。
- 备份别裸奔。各家收费差别不小：DigitalOcean 的自动备份收套餐价格的 20%，Hetzner 收 €0.012/GB/月并自动保留 7 天快照，Vultr 第一个快照免费。年付特价机型一般建议自己跑定时备份脚本，重要数据异地再存一份。
- 有公网暴露风险的，确认商家是否自带基础 DDoS 防护——Hetzner、OVH、Vultr 在网络边缘免费提供，DigitalOcean 和 Linode 包含在平台内，AWS 单独收费。

## 拿到机器后，先把这五件事做完

开通邮件到手只算完成一半，下面五件事做完才算能安心上线：

1. 更新系统，创建非 root 用户，配置 SSH 密钥登录，禁用 root 密码登录。
2. ufw 只放行需要的端口，装 fail2ban 挡爆破。
3. 建站就装 certbot 签免费 SSL 证书，别让站点裸跑 HTTP。
4. 配自动备份：数据库每天导出，站点目录定期打包，传到对象存储或另一台机器。
5. 前面套一层 Cloudflare，把源站 IP 藏起来，能挡掉大部分扫描和低强度攻击。

系统栈不用花哨，Ubuntu 24.04 LTS、Nginx、PHP 8.3、MariaDB 这套组合对绝大多数建站需求都够用，多余组件只会增加维护负担。
